# Обезличенные учебные примеры

В папке находятся два связанных файла:

1. `library_schedule_source.txt` — вымышленный исходный документ.
2. `intentionally_wrong_answer.md` — намеренно ошибочный ответ для анализа.

Все названия, даты, адреса и контакты вымышлены. Материалы не описывают реальную организацию или человека.

## Учебная задача

Сравнить ответ с источником и отметить:

- какие утверждения подтверждены;
- какие противоречат источнику;
- для каких утверждений основания нет;
- какой безопасный следующий шаг должен сделать человек.

## Ожидаемый принцип ответа

Участник не обязан угадывать «правильную формулировку». Он должен связать каждое проверяемое утверждение с конкретной строкой источника либо честно отметить отсутствие основания.
