# PilotLab

> **Ты не пассажир. Ты — пилот.**

**«Интеллект — это ты»** — первый базовый курс PilotLab.

PilotLab — исследовательский B2C-прототип ежедневного тренажёра самостоятельной, осмысленной и безопасной работы с ИИ для людей без технического бэкграунда.

> Позиция продукта: **ты — субъект, ИИ — инструмент**. Пользователь ставит задачу, проверяет основания и принимает решение; система помогает пройти этот путь небольшими шагами.

> Это демонстрационный MVP, а не готовый образовательный сервис и не продукт Сбера. В нём нет подключения к LLM, регистрации, загрузки файлов и удалённой аналитики.

## Проблема

Пользователь может получить убедительный ответ от нейросети, но при этом не уметь:

- поставить проверяемую задачу;
- исключить персональные и чувствительные данные;
- отличить версию от установленного факта;
- исправить запрос, не меняя всё сразу;
- принять собственное решение и объяснить его.

## Гипотеза

Если давать одну короткую практическую миссию, разрешать повтор без штрафа и выдавать помощь тремя уровнями, пользователь будет меньше бояться ошибки и чаще завершать новую задачу самостоятельно.

## Что показывает демо

- две короткие миссии;
- самостоятельный режим и режим куратора;
- три уровня подсказок;
- ветку «получилось иначе»;
- повтор без потери XP;
- личную карту прогресса без рейтинга;
- локальное хранение прогресса на устройстве;
- крупный текст, заметный фокус и клавиатурную навигацию.

## Запуск

Установка не требуется.

1. Скачайте репозиторий.
2. Откройте файл `index.html` двойным щелчком.

Или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## GitHub Pages

Репозиторий готов к публикации как статический сайт из корня ветки `main`. Подробная инструкция находится в [`docs/PUBLISH_TO_GITHUB_RU.md`](docs/PUBLISH_TO_GITHUB_RU.md).

## Что собирается

Ничего не отправляется на сервер. Прогресс, режим и количество использованных подсказок сохраняются только в `localStorage` текущего браузера. Тексты ответов не выгружаются.

Подробнее: [`docs/PRIVACY.md`](docs/PRIVACY.md).

## Архитектура и статус

- Текущая версия: автономный HTML/CSS/JavaScript-прототип.
- Следующая версия: backend, LLM-шлюз, правила безопасности, событийная аналитика и панель куратора.
- Агенты, RAG, генерация медиа и загрузка пользовательских файлов не входят в текущий MVP.

Схема: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
