# Конфиденциальность публичного MVP PilotLab

## Коротко

Прототип не подключён к LLM и не отправляет введённые ответы разработчику. Прогресс хранится в `localStorage` браузера на текущем устройстве.

## Какие данные сохраняет приложение

- факт начала демо;
- выбранный режим;
- номер текущей миссии;
- завершённые миссии;
- XP;
- количество попыток;
- количество открытых подсказок;
- настройку крупного текста.

## Какие данные приложение не должно получать

- имя и фамилию;
- телефон и электронную почту;
- адрес;
- данные документов;
- медицинские, финансовые и служебные сведения;
- пароли, токены и ключи API;
- реальные пользовательские файлы.

## Где находятся данные

Данные приложения остаются в браузере. Пользователь может удалить их кнопкой «Начать демо заново» или очисткой данных сайта в настройках браузера.

## Ограничение

При публикации через GitHub Pages сам хостинг может обрабатывать технические данные посетителей, например IP-адрес, в соответствии с политикой GitHub. Это не является аналитикой данного прототипа.

## Перед пилотом с реальными пользователями

Нельзя просто подключить LLM и начать собирать ответы. Сначала необходимо:

1. утвердить перечень и сроки хранения данных;
2. определить правовое основание обработки;
3. подготовить информированное согласие и понятное уведомление;
4. исключить детей из первого пилота либо разработать отдельный контур родительского согласия;
5. провести проверку безопасности и сценариев утечки;
6. обеспечить удаление данных по запросу участника.
